# Building Space Cadet HD for Windows x64

The game is based on SpaceCadetPinball 2.1.1 DEV, commit `cb9b7b886244a27773f66b0b19fdc2998392565e`. Table components and Classic scoring rules come from that revision. In 7.0 the engine recalculates the remaining time after each contact, samples mirrored flipper sweeps equally and accounts for ball spin. The HD renderer receives the ball's orientation. [Upstream engine revision](https://github.com/k4zmu2a/SpaceCadetPinball/commit/cb9b7b886244a27773f66b0b19fdc2998392565e)

## HD 7.0.2

The moving body of the upper-left bumper in the group of three now lines up with its socket. Its eight HD frames (388–395) are generated by `tools/art-v2/render_parts.py`. The mount and cap follow the perspective of the original table. The same DAT supplies the collision geometry and game events.

New profiles select the GeneralUser GS bank. Music volume defaults to 64 out of 128 and table effects to 128 out of 128. Music starts switched off. Display settings include an edge-smoothing option for the ball and individual HD components. The poster artwork restores the edge of the planet at the left frame. See `README.md` and `docs/screenshots` for the remaster overview, controls and screenshots.

## Building the engine

The verified configuration uses Visual Studio 2022 with the Desktop development with C++ workload and Windows SDK, MSVC x64, CMake 3.22.2, SDL 2.32.10 and SDL_mixer 2.8.1. Extract `SDL2-devel-2.32.10-VC.zip` and `SDL2_mixer-devel-2.8.1-VC.zip` into `deps` at the source root. [SDL release](https://github.com/libsdl-org/SDL/releases/tag/release-2.32.10) · [SDL_mixer release](https://github.com/libsdl-org/SDL_mixer/releases/tag/release-2.8.1)

Open PowerShell at the source root and build the game.

```powershell
$sdlPath = (Resolve-Path .\deps\SDL2-2.32.10).Path
$mixerPath = (Resolve-Path .\deps\SDL2_mixer-2.8.1).Path
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 "-DSDL2_PATH=$sdlPath" "-DSDL2_MIXER_PATH=$mixerPath" "-DCMAKE_WIN32_EXECUTABLE:BOOL=ON"
cmake --build build --config Release --parallel
```

Alternatively, run `.\BuildForWindows.ps1` with the same directory layout. The executable requires the MSVC 2015–2022 x64 runtime. The packaged game includes its libraries alongside the executable.

The build writes `SpaceCadetHD.exe`, `SDL2.dll` and `SDL2_mixer.dll` to `bin\Release`. Copy `Data` and `HD` there from a game build. To recreate these folders from original assets, populate `Data` as shown below and generate `HD` as described in the next section.

```powershell
$gameData = New-Item -ItemType Directory -Path .\bin\Release\Data -Force
Get-ChildItem -LiteralPath 'C:\Games\pinball' -File | Where-Object Extension -In '.DAT', '.WAV', '.MID' | Copy-Item -Destination $gameData.FullName
```

The verified `PINBALL.DAT` is 928,700 bytes and has SHA-256 `42DEFD5D2A339A3953FE643716AFF4E35B2CEA7A3E54505C82D1E78D5325BC04`. The source installation contains 60 WAV files. Six WAV names referenced by the DAT are absent from that copy: SOUND2, SOUND37, SOUND44, SOUND52, SOUND59 and SOUND62. The music is in `PINBALL.MID`. The file `PINBALL2.MID` contains a bitmap font.

## Generating the 4× textures

The build uses two local master images in `tools/art-v2`. The repainted table in `board-source.png` is aligned with game coordinates. The backglass artwork is in `backglass-generated.png`. Frame numbers, object positions and display dimensions come from the Windows DAT.

Use 64-bit Python 3.10 and install the dependencies in a virtual environment. The build machine used Python 3.10.10, PyTorch 2.5.1+cu121, NumPy 1.22.4, SciPy 1.8.1, Pillow 10.0.0 and a GeForce RTX 4080. The commands below use CUDA 12.1. For a CPU build, use the PyTorch index `https://download.pytorch.org/whl/cpu`. CUDA computes the base layer in FP16 and the CPU uses FP32, so individual color values may differ. The release uses the system font Bahnschrift for the BALL label. The generator falls back to DejaVu Sans if installed.

```powershell
py -3.10 -m venv .venv
$python = (Resolve-Path .\.venv\Scripts\python.exe).Path
& $python -m pip install numpy==1.22.4 scipy==1.8.1 pillow==10.0.0
& $python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

Place `realesr-general-x4v3.pth` at the source root. Its SHA-256 is `8DC7EDB9AC80CCDC30C3A5DCA6616509367F05FBC184AD95B731F05BECE96292`. The generator checks the weights and source DAT before processing. [Real-ESRGAN weights](https://github.com/xinntao/Real-ESRGAN/releases/download/v0.2.5.0/realesr-general-x4v3.pth)

```powershell
& $python .\tools\art-v2\bake.py .\bin\Release\Data\PINBALL.DAT .\bin\Release\HD --weights .\realesr-general-x4v3.pth
```

First, `tools/upscale.py` creates a temporary base of 318 BMP files. Then `render_parts.py` builds the components and draws 116 unlit inserts on the table. The generator calculates coverage masks at 4× resolution. The DAT depth map determines where walls and rails cover a lens. Finally, `bake_backglass.py` assembles the backglass. HD 4 produces 630 BMP files covering 318 original group IDs, four extra discharge frames, two spinner atlases and 306 masks.

Keep the base when working on individual components. The two commands below run the same stages separately. After changing a material or pattern, rerun only the second command.

```powershell
& $python .\tools\upscale.py .\bin\Release\Data\PINBALL.DAT .\realesr-general-x4v3.pth .\build\HD-base
& $python .\tools\art-v2\bake.py .\bin\Release\Data\PINBALL.DAT .\bin\Release\HD --base .\build\HD-base
```

To replace the painted table, run `tools/art-v2/register_board.py` with three paths: the 730 × 940 reference image of the original table, the new artwork and the output 1460 × 1880 PNG. This step also requires `opencv-python-headless==4.10.0.84`. The standard build already includes the aligned table.

In HD 3, separate sprites and the fixed table artwork together define the shapes of the nine drop targets. Both spinners rotate around fixed axes. Across the eight plunger positions, the steel spring changes pitch while its lower mount stays fixed. The backglass artwork change was confined to the pilot's eyes.

HD 4 generates a 32-position atlas for each spinner. Rendering follows the time remaining until the next original spin event. Game logic still uses the eight original positions. The side-wall mask follows straight lines in perspective. The visible area of each lens determines the shape of its HDR highlight.

In HD 5, `route_inserts.py` builds perspective outlines for 23 mission arrows. Their vertices come from the difference between lit and unlit frames in the original DAT. For the purple ramp, `purple_ramp.py` transfers fine surface detail from the upper curve onto the adjacent plate. The tilt of the red lite198 lens follows its colored outline. Verification produces `detail5-dat-*.bmp` and `detail5-hd-*.bmp` to compare matching states in both graphics modes.

`TableRelief.cpp` reconstructs a surface in camera space from the depth maps and updates the affected areas when a mechanism moves. For visible points on the ball, `HdRenderer.cpp` casts reflected rays and tests them against that surface on the CPU. `RailReflections.cpp` calculates the ball's reflection in metal parts. The camera matches the original viewpoint. `CabinetEffects.cpp` animates galaxies and electric arcs, and `FieldTraces.cpp` sends pulses along the table artwork.

## Game settings

HD 4 starts a new game with the original light sequence. New profiles use Classic mode with table sounds on and music off. The Meditative checkbox beside Play persists across launches. In this mode, fuel is preserved, side kickbacks rearm and a well-timed swing can reach a ball that would just miss both tips. Without a swing the ball drains. Nudges are weaker and rate-limited. A top-five score is saved at game over and again when the player confirms a new name. Switch between the two high-score tabs with the mouse or controller shoulder buttons. Both tables support HD 2 and HD 3 profiles.

Esc opens the menu, F2 starts a new game and F3 pauses. F7 cycles through the available window scales in 0.5× increments, fullscreen and the original size. The first window fits the desktop work area. F4 or a double-click toggles fullscreen. To bind an action in Controls, select it and press a key, mouse button or controller button. The left and right Shift keys or controller bumpers operate the flippers by default. Pull the right stick to set spring tension and release it to center to launch. The left stick nudges the table from the left, right or bottom. Each stick gesture can be disabled independently.

Switch between Russian and English during play to change the interface and table messages. The information and mission panels use the dot-matrix font in `CabinetDisplay.cpp`. The two lens colors come from the original score display's digit palette. Words wrap within the dimensions the DAT specifies for each panel. Active dots get an HDR boost.

## HD 6

F1 opens Help in the current language. Space ends the opening light show or starts another game after game over. During play it retains its plunger binding. The blue-violet matrix color was checked against the score display in the original Windows game.

`tools/art-v2/lane_detectors.py` builds the fixed sockets and moving tabs for eleven lanes. The original sensors and collision code determine their positions and states. `cabinet_sky.py` draws two small galaxies. `CabinetEffects.cpp` handles sky motion and rare flares, and `FieldTraces.cpp` controls the central disc's breathing glow.

## HD 6.1

Losing focus or minimizing the window pauses the game. In 6.1, returning from an automatic pause or resuming through F3, the menu or Help starts a three-second countdown on SDL's monotonic clock. Game timers and physics resume on GO! The overlay is defined in `ResumeOverlay.h`. Fullscreen uses the current desktop display mode.

The plunger animation has 113 positions, including the eight original poses. The build generates `HD/plunger-motion.bin` alongside the BMP files. In Meditative mode the tip-hit allowance is extended by 6% of the ball diameter. Backglass exhaust flares recur every 38–54 seconds of game time. The two headlights briefly glint roughly every two minutes.

Hints for F1, Esc and F4/F7 remain visible below the display throughout play. Tests compare letter and digit LEDs in the same frame, measuring brightness and color in the linear FP16 scRGB buffer at widths of 600, 900 and 1200 pixels. For silent tests, set `$env:SDL_AUDIODRIVER = "dummy"` in PowerShell. The mixer then processes music and effects through a virtual output.

The standard HD directory contains 631 BMP files. `bake_planet.py` builds the green planet's surface map from the backglass master. One rotation takes 300 seconds of game time. Four backglass stars flare in turn for 1.85 seconds each. The central disc retains a lit core in both phases of its cycle. Classic rules are checked against the same 2,400-step reference trace.

The recovery archive contains `Recovery/Reference/plunger-HD6.csv`, recorded with HD 6. The verification scenario reproduces five button pulls and four analog-stick pulls, including a partial return before release. Run the executable with `-verify -sw -reset` in a separate process with `SPACECADET_VERIFY_LAUNCH=1`, `SPACECADET_VERIFY_DIR` pointing to an existing test directory, `SDL_VIDEODRIVER=dummy` and `SDL_AUDIODRIVER=dummy`. Compare the resulting `launch.csv` with the reference. Its 3,296 steps record spring force, firing threshold, ball position, direction, speed and score. ## HD 6.2

The game settings include a persistent resume countdown, enabled by default. Each digit (3, 2, 1) lasts 700 ms, followed by the localized GO! message for 400 ms. The final 300 ms leave the table unobstructed while the ball and game timers remain paused. A brief light cue draws attention to the ball before play resumes. With the countdown disabled, play resumes immediately.

The Cyrillic glyph masks have been revised. The coordinates of lit LEDs define each letter. Individual LEDs use the same size, color and brightness settings as the score display. English letters still use the original `PB_MSGFT` font.

Both panels use fixed dot spacing. Short messages fit on one line and longer messages wrap to the available lines. If a message exceeds the panel capacity, the rest appears on the next page. `MatrixLayoutChecks62.h` tests wrapping and pagination.

Space resumes play after a manual F3 pause. With the menu open, Space confirms a selection. To verify the countdown setting persists, run the game twice with the same isolated `SPACECADET_VERIFY_DIR` and `SDL_AUDIODRIVER=dummy`. On the first run use `SPACECADET_SCORE_TEST=settings-write` and `-verify -reset`. On the second use `SPACECADET_SCORE_TEST=settings-read` and `-verify`.

As its spin winds down, the left spinner turns around its axis into a visible resting position. This is the final phase of the HD animation. The original game mechanism awards the points. `SpinnerRestChecks62.h` checks the resting position.

The rail and the three yellow targets on the right have refined outlines. This changes the background `107.bmp`, the three sprites `432.bmp`–`434.bmp` and their masks. The build recipe in the archive reproduces all seven images.

## Verification

From the source root, run two games in PowerShell using isolated profiles. The checks write the trajectory, score and lamp states to `trace.csv` and the results to `report.txt`. Verification also saves SDR screenshots for visual comparison.

```powershell
$exe = (Resolve-Path .\bin\Release\SpaceCadetHD.exe).Path
$env:SDL_AUDIODRIVER = 'dummy'
$env:SDL_VIDEODRIVER = 'dummy'
try {
    foreach ($mode in 'classic', 'meditative') {
        $qaProfile = New-Item -ItemType Directory -Force -Path ".\build\qa-$mode"
        $env:SPACECADET_VERIFY_DIR = $qaProfile.FullName
        $testArgs = @('-verify','-sw','-reset')
        if ($mode -eq 'meditative') { $testArgs += '-meditative' }
        $game = Start-Process -FilePath $exe -ArgumentList $testArgs -WindowStyle Hidden -Wait -PassThru
        Get-Content -LiteralPath (Join-Path $qaProfile.FullName 'report.txt')
        if ($game.ExitCode -ne 0) { throw "Verification failed in $mode mode, exit code $($game.ExitCode)" }
    }
} finally {
    Remove-Item Env:SPACECADET_VERIFY_DIR -ErrorAction SilentlyContinue
}
Get-FileHash .\build\qa-classic\trace.csv -Algorithm SHA256
```

Compare `trace.csv` with `Recovery/Reference/classic-HD7.csv` and `launch.csv` with `Recovery/Reference/plunger-HD7.csv`. Version 7.0 produced both references. The archive also retains the original engine trajectories and nine HD 6 launches for historical comparison. Because of the physics changes, their coordinates can diverge from HD 7 after the first impact.

Checks cover window sizing and F7, HDR switching, the audio mixer, virtual Xbox and DualSense controllers with analog sticks, center drains, late flipper hits, repeated activation of both kickbacks, fuel, scoring and lamp states. To verify monitor output, enable HDR in Windows and in the game, then look for `DXGI HDR active` in the report. Reported peaks come from measured FP16 framebuffer values. Measuring the panel's actual light output requires an external instrument.

Language-switching tests check that message IDs, the queue, timers and numeric substitutions survive the switch. Compare the same indicators in `game-ru.bmp` and `game-en.bmp`. On an HDR monitor, the test separately measures both LED panels and the background between their dots. The report entries `Fullscreen HDR information panel` and `Fullscreen HDR mission panel` give each panel's peak and the minimum between LEDs in the FP16 buffer.

The persistence test uses two launches with one test profile. First set `SPACECADET_SCORE_TEST=write` and run the executable with `-verify -reset`. Then set `SPACECADET_SCORE_TEST=read` and run the same executable with `-verify`. The reports `profile-write.txt` and `profile-read.txt` cover a Russian player name, automatic saving of a second score, mouse input and the shoulder buttons on Xbox and DualSense controllers. Clear the variable before running the full table test.
